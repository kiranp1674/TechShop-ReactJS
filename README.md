# 🛍️ TechShop – React.js E-Commerce Website

A modern and responsive e-commerce web application built using React.js. TechShop provides an online shopping experience where users can explore products, search and filter items, view product details, and manage their shopping cart.

## 🚀 Live Demo

🔗 **Live Website:** https://tech-shop-react-js.vercel.app/

🔗 **GitHub Repository:** https://github.com/kiranp1674/TechShop-ReactJS

## 📌 Project Overview

TechShop is a React.js-based e-commerce application developed to demonstrate modern frontend development concepts and practical React skills.

The application provides a user-friendly interface with product browsing, category filtering, product details, shopping cart management, and responsive layouts.

## ✨ Features

- 🏠 **Home Page:** Attractive homepage with a hero slider and featured products.
- 🛒 **Product Listing:** Browse available products.
- 🔍 **Product Search:** Search for products easily.
- 📂 **Category Filtering:** Filter products based on categories.
- 🏷️ **Brand Filtering:** Find products by brand.
- 💰 **Price Sorting:** Sort products according to price.
- 📱 **Product Details:** View individual product information and image galleries.
- 🛍️ **Shopping Cart:** Add products to the cart.
- ➕ **Quantity Management:** Increase or decrease product quantities.
- ❌ **Remove Products:** Remove unwanted products from the cart.
- 💾 **Local Storage:** Maintain cart information after refreshing the page.
- 🔐 **Login & Signup:** User authentication interface.
- 📱 **Responsive Design:** Supports desktop, tablet, and mobile screens.
- 🚫 **404 Page:** Handles unavailable routes.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/kiranp1674/TechShop-ReactJS.git
```

**2. Navigate to the project directory**

```bash
cd TechShop-ReactJS
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in your browser**

```text
http://localhost:5173/
```

## 🏗️ Build for Production

To generate the production-ready build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
